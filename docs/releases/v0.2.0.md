# v0.2.0 — Independent search and adaptive layouts / 独立搜索与自适应布局

## 简体中文

### 本次发布内容

- 正常有线连接改用原生显示器图标；连接中、断开、无路由、无线及 VPN 状态保留原图标，停用时恢复。
- 搜索按钮与可配置的 `Super+S` 打开独立本地面板，不再打开 Start。即使关闭 Start，仍可搜索应用及最近文件 / 文件夹；支持 Esc、方向键、回车和外部点击透传。
- 默认自动选择任务栏 40 / 48 / 56 逻辑尺寸、搜索框 / 带文字图标 / 图标、六列 / 八列 Start。保留手动设置及明确保存的旧选择，4K 200% 缩放不会重复放大逻辑空间。
- 应用过多时先缩搜索，再约束并滚动应用条；真实滚轮及键盘激活可重新显示目标按钮，不无限缩小按钮或覆盖系统控件。
- Recommended 可开关，并按文件 / 文件夹、包含 / 排除目录、类型 / 扩展名、访问时间及数量过滤。排除优先，软链接原路径及目标同时校验；关闭后回收空间给固定项。
- Start、搜索和 Jump List 共用异步最近项目读取器及缓存；没有全盘扫描、网络搜索或持久化查询历史。Start 的推荐规则不影响显式搜索或应用自己的跳转列表筛选。
- 桌面 Peek 与缩略图 Peek 共用透明度所有权，保留稳定原值，不把已淡出的值或原生动画中间值当作永久基线；不取消窗口的原生位置 / 缩放过渡。
- GTK 4 最大化标题栏移除扩展可控的 padding / margin。Mica 目标分类避免仅凭加载 GTK 库误判已知浏览器 / Electron / Qt 渲染器。
- 偏好页使用原生 Adw / GTK 控件，支持目录增删、推荐筛选、自动 / 手动模式、搜索快捷键和边缘接管者说明。

### 兼容边界

只声明支持 **GNOME Shell 50**。自动阈值是项目自适应策略，不是 Windows 实测数字。GTK 4 标题栏样式不代表已经改写 Edge / Chromium 自绘圆按钮的客户端边距；不裁剪整窗，不覆盖假的关闭按钮。GTK 样式 / Mica 仍默认关闭，扩展 ZIP 不替换 GTK、Mutter 或浏览器软件包。

最近项目只考虑 XBEL 已记录的本地路径；默认不推荐隐藏项目，跳过消失、断开或无权读取的条目。缺失时间保持未知，只在不限时间时推荐，不使用磁盘 mtime。缓存查询有实际外层超时，慢挂载即使未响应取消也不能占住缓存读取入口。

Tiling Assistant 启用时仍拥有边缘拖动；停用后由本扩展接管并在结束时恢复原生边缘贴靠的先前状态。本次不改变电池判断逻辑。`v0.1.0` 的标签与附件保持不变。

## English

### Included in this release

- Healthy wired connections use a native computer glyph while other network states remain distinct and teardown restores the original icon.
- Search opens an independent local panel through the taskbar button or configurable `Super+S`, even with Start disabled. Apps, recent files and folders have separate scopes, keyboard navigation, Enter activation, Escape and outside-press delivery.
- Automatic taskbar thickness, search presentation and six-/eight-column Start are derived from each monitor's logical space. Manual settings and explicitly saved legacy choices remain intact; 4K at 200% scaling does not double the logical layout.
- Crowded app strips use bounded scrolling instead of shrinking buttons without limit or covering the system controls; actual wheel input and keyboard reveal are covered by regressions.
- Recommended has on/off, file/folder, directory, type/extension, access-time and post-filter count controls. Exclusions take precedence, including symlink targets. Disabling it returns the space to pins.
- Start, search and Jump Lists share an asynchronous local XBEL cache with an outer deadline. No full-disk scan, web search or persistent query history; recommendation rules remain separate from explicit search and per-app Jump Lists.
- Shared Peek opacity ownership retains the stable original state and does not cancel native scale/position transitions. GTK 4 maximized title bars remove extension-controlled padding/margins; Mica classification excludes known self-drawn renderers instead of relying solely on a loaded GTK library.
- Native Adw/GTK preferences expose directories, filters, automatic/manual modes, search shortcuts and edge-ownership guidance.

### Boundaries and verification

Only **GNOME Shell 50** is declared supported. Automatic thresholds are project policy, not measured Windows metrics. Edge/Chromium's custom caption spacing remains client-owned. GTK styling/Mica stay opt-in; the ZIP replaces no native libraries or browser packages. Battery logic is unchanged, and the `v0.1.0` tag/assets are preserved.

Portable checks and all seven package tests passed. Both complete default and Ubuntu/Yaru isolated graphical suites exited successfully with zero failures, including runtime and shutdown log gates. New focused coverage includes 27 search/recommendation checks, 24 search-style checks, 11 adaptive/overflow checks, actual virtual keyboard/wheel input and the native preferences window. An additional display matrix passed 11 checks each at 1366×768, 2560×1440, physical-coordinate 4K/200% and logical-coordinate 4K/200%, plus eight dual-monitor checks; their runtime/shutdown logs were clean. No real desktop captures, real input injection or JavaScript hot reload were used; hardware controls used isolated fixtures. Hosted Actions performs portable checks and packaging, not the workstation's full GNOME 50 graphical suite.

## 安装 / Install

Download the ZIP and `SHA256SUMS` into the same directory / 将 ZIP 与 `SHA256SUMS` 下载至同一目录：

```sh
sha256sum --check SHA256SUMS
gnome-extensions install --force win11-taskbar@altarscn.com.shell-extension.zip
# 注销并重新登录 / Log out and back in.
gnome-extensions enable win11-taskbar@altarscn.com
```

GitHub Actions publishes the exact checked installation ZIP and checksum; the Gitea mirror receives the same downloaded artifacts, not a separate rebuild.
