# v0.1.0 — Initial public release / 首次公开发布

## English

Windows 11-style taskbar for **GNOME Shell 50**, with Start, configurable search, live window previews, tray overflow, quick settings, notifications and snap layouts.

### Included in this release

- Restore Windows' **combined network/volume/battery button**, with one shared hover/pressed surface.
- Draw a visible, independent separator for the show-desktop area; preserve click-to-minimize/restore and desktop peek.
- Keep quick-setting toggles and arrows visually connected, with a shared outer frame and keyboard-focus outline; preserve each region's native action.
- Search supports hidden, icon, icon + label and search-box styles.
- Snap layouts support `Super+Z`, maximize-button hover, the drag-to-top strip, edge/corner snapping and snap assist.
- Window corners/shadows cover GTK, Chromium/Electron and Xwayland windows. GTK title bars and Mica remain opt-in.
- English and Simplified Chinese READMEs, with installation, compatibility, conflict and build instructions.
- GitHub Actions builds an installable ZIP with compiled GSettings schemas and `SHA256SUMS`. Version tags publish those same artifacts as a Release.

### Validation

- Local full graphical regressions: **519 reported checks in each of the default and Ubuntu/Yaru modes**, completed with zero failures; runtime and shutdown logs were checked.
- Portable syntax/pure-logic/schema/application-order checks passed.
- Seven package tests passed: layout, compiled-schema usability, checksum, reproducibility, tag/version agreement, invalid inputs and symbolic-link rejection.
- Hosted Actions runs the portable build and package checks. It does **not** claim to run the GNOME 50 graphical testbed.

### Install

Download both release assets into one directory:

```bash
sha256sum --check SHA256SUMS
gnome-extensions install --force win11-taskbar@altarscn.com.shell-extension.zip
# Log out and log back in.
gnome-extensions enable win11-taskbar@altarscn.com
```

Only GNOME Shell 50 is declared supported in this release. Conflicting docks/tray hosts should be disabled. Tiling Assistant keeps edge dragging while enabled. Optional GTK/Mutter patches are not installed by the ZIP.

## 简体中文

面向 **GNOME Shell 50** 的 Windows 11 风格任务栏，含开始菜单、可配置搜索、实时窗口预览、托盘溢出、快捷设置、通知中心及窗口贴靠。

### 本次发布内容

- 恢复 Windows 原生的**网络／音量／电池合并按钮**，整组共用悬停与按下背景。
- 显示桌面区域加入独立绘制的可见分隔线，保留点击最小化／还原与悬停预览桌面的行为。
- 快捷设置的主开关与箭头连成一体，共用外框和键盘焦点框，保留两侧原生动作。
- 搜索支持隐藏、仅图标、图标加文字和搜索框。
- 贴靠支持 `Super+Z`、悬停最大化按钮、拖到上缘布局条、边缘／四角贴靠与贴靠助手。
- 圆角与阴影覆盖 GTK、Chromium／Electron 和 Xwayland 窗口；GTK 标题栏和 Mica 仍需主动启用。
- 提供英文与简体中文 README，写明安装、兼容性、冲突和构建方法。
- GitHub Actions 生成包含已编译 GSettings schema 的安装 ZIP 与 `SHA256SUMS`，版本标签自动发布同一批产物。

### 验证情况

- 本地完整图形回归：默认模式、Ubuntu／Yaru 模式**各报告 519 项检查，均为零失败**，同时检查了运行与关闭日志。
- 可移植的语法、纯逻辑、schema 和应用排序检查通过。
- 七项安装包测试通过，覆盖结构、编译 schema 的可用性、校验和、可重复构建、版本标签及输入安全。
- 云端 Actions 执行可移植构建与安装包检查，**不冒充 GNOME 50 图形测试桌面**。
